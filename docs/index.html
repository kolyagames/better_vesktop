Better Vesktop

Two clients. One window.

Better Vesktop runs Vencord and BetterDiscord together, sandboxed.

Download for Windows View the source

Portable, no installer. Windows 10 and 11, 64-bit.

One plugin list for both clients

Vencord and BetterDiscord plugins sit side by side in one page, with one search and one set of filters. This is a small working copy of it: try the filters and the switches.

Sample data. In the app the list shows your own plugins, and the switches turn them on and off for real.

Plugins can't reach your computer

Stock BetterDiscord gives plugins full access to Node.js. Better Vesktop keeps Discord's window sandboxed, like Vesktop does, and gives BetterDiscord a small bridge instead.

Plugins can

  • read and write inside the BetterDiscord folder
  • open files you pick yourself in a file dialog
  • fetch websites and APIs on the internet
  • open links in your browser

Plugins can't

  • touch any other file or folder
  • reach localhost or devices on your network
  • start programs or open executables
  • post to Discord webhooks or send commands to the app

A plugin is still code running inside your Discord page, so it can see and change what the page shows. Install plugins from the BetterDiscord store or from authors you trust. You can loosen the limits in Data/settings.json under betterDiscord.

Install in a minute

There's nothing to install. Unpack the folder and run it.

  1. Download

    Get the latest zip from the releases page.

  2. Unpack and run

    Put the folder anywhere except Program Files and start better-vesktop.exe. If Windows SmartScreen warns you, choose More info, then Run anyway: the build isn't signed.

  3. Log in

    Sign in to Discord as usual. Everything is stored next to the app, so deleting the folder removes it.
